# Pinned runtime closure for the controller container.
#
# Installed with `pip install --no-deps`, so every transitive dependency is
# listed explicitly and the pin is the only authority. Versions match the
# resolved set recorded in pyproject.toml.
#
# Synthesis-only packages (aws-cdk-lib, constructs) are deliberately absent:
# the container never synthesizes infrastructure.
#
# No AgentCore runtime server library is pinned here, and that is a recorded
# choice rather than an oversight. AWS documents a custom agent as one built
# without the AgentCore Python SDK, served by FastAPI and Uvicorn, so that is
# what this image installs: the second block below is the FastAPI and Uvicorn
# closure the server layer needs. A dedicated AgentCore runtime server package
# is not installed in this environment, so its distribution name, import path
# and API cannot be verified, and pinning a guessed name would assert a fact
# nothing here can check.
#
# The contract the server implements (GET /ping, POST /invocations, port 8080,
# linux/arm64) is read from the AWS documentation, and the request headers
# InvokeAgentRuntime forwards are verified against the installed botocore
# service models for bedrock-agentcore and bedrock-agentcore-control, which
# boto3 and botocore below already carry.
