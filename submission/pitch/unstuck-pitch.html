Unstuck gets Decider 2B out of a decision loop.

Run 1 pays once.

Decider 2B makes tool decisions, but a new call can repeat a decision already proven useless. Unstuck turns that verified dead end into a Decision Receipt, so the same Decider chooses a new path, without a larger model taking over.

Unstuck 06 / 08

The private AWS execution path.

Private, signed model calls
After completion only
Controller
Amazon Bedrock AgentCore Runtime
executes every read
Decider 2B
private Amazon SageMaker endpoint
chooses, and only chooses
Outbound: nothing
Verifier and repair
deterministic code
owns outcome, receipt, repair
Narration
Amazon Bedrock Nova Lite
after the result is fixed

Network isolation on, private subnets, no address translation gateway and no internet gateway. Each signed call is bounded to one action on one resource.

Narration holds no authority. It is refused on a result that was never verified, which is what happened to Run 1.

No account, resource, or Region identifier is published. Nothing in the repository deploys or spends. #strands-decider-2b  #tool-selection
